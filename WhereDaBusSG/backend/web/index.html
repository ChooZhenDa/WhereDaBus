How do I collect historical observations?

The separate historical collector saves observations for the configured stops while Docker is running and your computer is awake. Opening Live arrivals alone does not collect history. Visit Half-hour trends and choose Today so far to inspect newly collected samples. Morning crowding uses weekday observations from 07:00 to 08:59 Singapore time.

After configuring SAMPLE_STOPS, start collection from PowerShell in the application folder:

docker compose --env-file .env --profile analytics up -d api sampler

Check it with:

docker compose --env-file .env logs --tail 5 sampler
What does this release include?

Live arrivals, nearby stops, direct routes, road-based searches, longest-route ranking, morning crowding, and half-hour historical trends. Direct routes shows adult card fares for a single ride where fare data is available. Use Feedback on an upcoming arrival to report a full, delayed or skipped bus. Journeys requiring transfers are outside this release. Saved stops remain in this browser. Direct routes includes boarding estimates and morning crowding. Save and name a journey to reopen its comparison.

Does Try demo query my database?

No. Demo mode generates clearly labelled synthetic examples in the browser. Use Live data with collected observations to demonstrate your actual PostgreSQL and MongoDB implementations.

Where is the backend API documentation?

Open API documentation on this application's address. Its port comes from your installation settings.

Why are there no nearby stops?

Try a wider radius and confirm the coordinates. The app needs imported bus stop data. Run Refresh-Data.cmd to refresh it.

Why are some routes missing?

Run Refresh-Data.cmd to import the route network. Usable route records are kept even when a service direction has gaps. Journeys crossing a gap are labelled partial, with unknown stop counts and distances. A gap elsewhere does not exclude your selected section. Direct routes searches for one bus serving the selected physical stops in the correct order; it does not guarantee current operation. Journeys requiring a transfer are not included.

How do live arrivals update?

Search a bus stop by name, road or code. Turn on Auto refresh to request updated arrivals every 20 seconds while the page is visible. Unknown capacity remains unknown.

Where are my saved stops stored?

They stay in this browser on this device. No account is needed. Demo stops and live stops are stored separately.

Where are my saved journeys stored?

Live journeys are stored in PostgreSQL. This browser keeps the private key used to access them. Clearing site data or using a different browser profile removes access to that list. Demo journeys are stored only in this browser.
