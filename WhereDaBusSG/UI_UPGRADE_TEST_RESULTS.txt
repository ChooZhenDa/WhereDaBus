LIMITS
The development environment had no actual Docker daemon, your Windows desktop,
your live PostgreSQL/MongoDB instances or your LTA credentials. Real database
integration tests and the Docker image build were not run here. The installer
was executed using PowerShell 7.4.7 on Linux with command mocks; Windows
PowerShell 5.1 syntax was used, but that runtime was not available for execution.
Browser HTTP fixtures are not evidence of queries against your installation.

REPRODUCING PROJECT TESTS (optional developer tools)
Install requirements.txt and requirements-test.txt in a Python environment:
  python -m unittest discover -s tests -p "test_*.py"
Install package.json devDependencies, then:
  npm test
These steps are not required to run the app; end users only need Docker Desktop.

Tests are verification evidence, not a grade prediction. Fares and transfer
planning remain unimplemented. Crowding analysis is not a query-speed benchmark.
