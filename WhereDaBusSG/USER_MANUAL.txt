User manual

START THE SUBMISSION ON WINDOWS

1. If you received the submission ZIP, extract it first. Then extract
   Source_Data_Manual.zip and open the WhereDaBusSG folder inside it.
   If you cloned the team repository, open its WhereDaBusSG folder.
2. Double-click Setup.cmd and wait for the website to open in your browser.
   Setup starts Docker Desktop if needed. On a fresh copy it loads the route
   network and all 85,724 observations. You can use these results without an
   LTA key.

Docker Desktop for Windows with Linux containers must be installed once.
The first launch downloads images and Python packages. Allow several minutes
for the build and data checks.

Morning crowding opens for service 860, stop 59059 and 18 November 2026.
All dates and times in these examples are Singapore time.

If this application folder already contains a valid live configuration in
.env, Setup reuses the existing site. It keeps the route network already
there, or loads the submitted network if the catalogue is empty. It adds
missing packaged readings within the live database's 90-day retention period.
If the recorded morning has expired there, Setup automatically opens the
same morning in the archived database.

EXPLORE THE APP

Morning crowding
  The report covers weekday arrivals between 07:00 and 08:59. Compare the
  total readings with the eligible readings. A reading is a prediction
  captured at one poll; several readings may describe the same bus.
  For the opening example all 34 eligible readings reported seats available.

Half-hour trends
  Open Half-hour trends from the menu. Choose stop 66359 and service 70M.
  Set both dates to 22 November 2026 and run the query. At 10:00, 26 of 30
  readings qualified and all 26 reported standing room available. At 10:30,
  18 of 27 eligible readings reported seats available. The crowding scores
  are 0 for seats available, 1 for standing room available, and 2 for
  limited standing room. A gap means there were no usable readings.

Direct routes and Saved journeys
  Open Direct routes. Select Blk 608 (59059) as the boarding stop and Yishun
  Int (59009) as the destination, then choose Find a route. Services 857,
  860 and 860T serve this trip. For service 860, PostgreSQL returns 12 stops
  and 4.6 km. Save the trip with a name, then open Saved journeys in the
  same browser to reopen, rename or delete it.

Other features
  Use Nearby stops to search around coordinates, Routes by road to look up
  a road, and Longest routes to compare route distances. Saved stops keeps
  shortcuts in this browser. Current boarding times and Feedback on an
  upcoming arrival require the live app described in START_HERE.txt.

STOP AND REOPEN

Use Stop-Review.cmd to stop the archived app or Stop.cmd to stop the live
app. Both keep their data. To reopen from the packaged application folder,
double-click Setup.cmd. Leave the folder's configuration files in place.
If a build fails, check Docker Desktop and your connection, then rerun Setup.
If the browser does not open, use the local address printed in the window.


DATA AND EVIDENCE

data/postgresql.sql holds 5,209 stops, 804 service directions and 26,946
ordered route entries. data/samples.zip holds the 85,724 original MongoDB
observations. The earliest was recorded on 18 November 2026 at 06:59 and
the latest on 23 November at 01:30, Singapore time. Coverage varies by stop.

data/EXPORT_METADATA.json records the export details. data/snapshot-results.json
holds the SQL route results and MongoDB query outputs used for the release
checks. The evidence folder contains the original database audit, CRUD tests,
query timings, screenshots and release checks. The original audit predates
the final export. The file hashes are listed in SUBMISSION_MANIFEST.json.

OPTIONAL LIVE COLLECTION AND BACKUPS

To start collecting new predictions or reconfigure an LTA key, open PowerShell
in the application folder and run .\Setup.cmd --live. See START_HERE.txt for
sampling and optional backups. To transfer new history between PCs, use
Export-Samples.cmd on the source and Restore-Samples.cmd on the destination.
